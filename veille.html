Qu'est-ce que GitHub ?

Fondée en 2008, GitHub est la plateforme de développement collaboratif la plus utilisée au monde. Rachetée par Microsoft en 2018 pour 7,5 milliards de dollars, elle est devenue bien plus qu'un simple hébergeur de code : c'est l'environnement de travail central de millions de développeurs.

Fonctionnalités clés
  • Hébergement de code — dépôts publics et privés, gestion des versions avec Git, collaboration en équipe.
  • GitHub Actions — automatisation des tests et du déploiement depuis le dépôt, sans serveur externe.
  • GitHub Pages — hébergement de sites web statiques gratuit. J'utilise cela pour mon portfolio.
  • GitHub Copilot — assistant IA intégré à l'éditeur qui suggère du code en temps réel.
Focus — GitHub Copilot
L'IA dans votre éditeur

Lancé en 2022, Copilot analyse votre code en temps réel et propose des suggestions basées sur des milliards de lignes de code public. Il est gratuit pour les étudiants via GitHub Education.

  • Suggestions de code en temps réel
  • Complétion automatique de fonctions
  • Explique du code existant
  • Génère des tests unitaires
Les limites
  • Peut suggérer du code incorrect
  • Il faut comprendre ce qu'on accepte
  • Débat ouvert sur le droit d'auteur
